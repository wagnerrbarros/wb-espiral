# wb-espiral

Visualização interativa 3D da **Espiral de Fibonacci** — camadas matemáticas da consciência.

Construído com Three.js. Explora a relação entre a sequência de Fibonacci, a proporção áurea (φ) e a estruturação do espaço em ângulos de 90°.

## Estrutura

`
wb-espiral/
├── index.html          # Visualização principal
├── README.md           # Este arquivo
├── .gitignore
├── docs/               # Documentação matemática/filosófica
└── experimentos/       # Variações e parâmetros testados
`

## Como usar

Abra index.html em qualquer navegador moderno.

- 🖱️ **Arraste** para rotacionar
- 🔍 **Scroll** para zoom
- 🔄 **Clique direito** para pan
- 🎛️ **Botões** no canto superior direito para toggle de camadas

## Conceito

A espiral logarítmica segue a equação r(θ) = A × e^(Bθ), onde B = ln(φ) / (π/2). A cada 90° o raio multiplica por φ ≈ 1.618.

As 8 camadas representam estágios de expansão, com portais dourados marcando cada salto quântico de escala.
